# Server (Go)

## Run it

```bash
pnpm db:up                     # Postgres 16 in Docker on localhost:5433
pnpm db:migrate                # goose: apply migrations/*.sql
pnpm db:reset                  # truncate all rows (local dev); production needs RESET_DB=1
cp apps/server/.env.example apps/server/.env   # then: set -a; source apps/server/.env; set +a
pnpm server                    # hot reload (air) on http://localhost:8787
```

Try it without any OAuth app (local only):

```bash
DEV_AUTH=true pnpm server
TOKEN=$(curl -s -XPOST localhost:8787/v1/dev/token -d '{"email":"me@example.com"}' | jq -r .accessToken)
curl -s localhost:8787/v1/users/me -H "Authorization: Bearer $TOKEN"
```

API reference: [`api/openapi.yaml`](api/openapi.yaml) (open it in https://editor.swagger.io or the Redocly VS Code extension).

## Tests

| Command                                          | What runs                                                                         |
| ------------------------------------------------ | --------------------------------------------------------------------------------- |
| `go test ./...` (`pnpm test`)                    | Unit tests: table-driven, with fakes, no DB                                       |
| `pnpm -F @authenticator/server db:create-test`   | Once: creates `authenticator_test`                                                |
| `pnpm -F @authenticator/server test:integration` | Real Postgres + real HTTP: vault, sync, conflicts, tombstones, passkeys, activity |

## A tour for Go learners

Read in this order:

1. `cmd/api/main.go` — the program starts here: config → DB pool → router → server with graceful shutdown.
2. `internal/app/router.go` — **dependency injection by hand**: every module is `NewRepository → NewService → NewHandler`, then mounted.
3. `internal/modules/users` — smallest complete module. Then `devices` (transactions), `vault`, `sync` (the interesting one), `auth`, `passkeys`.
4. `internal/db` — generated by sqlc from `queries/*.sql`. Change SQL → `pnpm db:generate`. Schema changes → new file in `migrations/`.

| Go idea                 | Where to see it                                                                                             |
| ----------------------- | ----------------------------------------------------------------------------------------------------------- |
| Interfaces as "ports"   | `Repository` in each module; `IDVerifier`, `FacebookProfiles` in `auth/providers.go`                        |
| Fakes for testing       | `auth/service_test.go`, `sync/service_test.go` (in-memory repos)                                            |
| Table-driven tests      | `[]struct{ name ...; want ... }` + `t.Run` in every `_test.go`                                              |
| Errors are values       | `errors.Is(err, pgx.ErrNoRows)`, sentinel errors like `ErrInvalidRefresh`, `errors.Join` in passkeys        |
| Transactions            | `auth/repository.go` `FindOrCreateUser`, `sync/repository.go` `Apply` (`Begin`, `defer Rollback`, `Commit`) |
| Row locking             | `LockVaultItem` (`SELECT … FOR UPDATE`) in `queries/sync.sql`                                               |
| `context.Context`       | first argument everywhere; `context.WithoutCancel` in `audit` so logging survives a closed request          |
| Middleware              | `internal/middleware`: a func that takes a handler and returns a handler                                    |
| `embed`                 | `migrations/embed.go` bakes SQL into the binary                                                             |
| Crypto from the std lib | `crypto/ecdsa`, `sha256`, `hmac` in `pkg/` and `softauthn_test.go`                                          |

## Layout

```text
apps/server/
├── cmd/                     # Application binaries (entry points)
│   ├── api/main.go          # Standalone server daemon (local dev, Docker, K8s)
│   └── migrate/main.go      # CLI database migration tool (Goose)
├── api/
│   └── index.go             # Vercel Serverless entry point
├── internal/                # Private application code (Go compiler enforced)
│   ├── app/                 # Composition root & wiring
│   │   ├── router.go        # Builds dependencies, registers Chi routes & middleware
│   │   ├── serverless.go    # Cold-start handler & pooled connection lifecycle
│   │   └── maintenance.go   # /v1/internal/cleanup cron handler
│   ├── config/              # Environment config loading & validation
│   ├── platform/            # Low-level infrastructure adapters
│   │   ├── database/        # pgx connection pool & InTx transaction runner
│   │   ├── httpserver/      # net/http wrapper with timeouts & graceful shutdown
│   │   └── logger/          # slog structured logger
│   ├── middleware/          # Cross-cutting HTTP middleware
│   │   ├── middleware.go    # JWT Bearer auth & context extraction (UserID, SessionID)
│   │   └── security.go      # CSP, HSTS, CORS headers & rate limiting
│   ├── db/                  # Generated type-safe sqlc query layer
│   └── modules/             # Business domain feature slices
│       ├── auth/            # OAuth2 (Google/Apple/Facebook), refresh token rotation
│       ├── vault/           # Zero-knowledge vault key envelopes & Argon2id KDF
│       ├── sync/            # Optimistic concurrency sync engine & vault items CRUD
│       ├── passkeys/        # WebAuthn/FIDO2 registration & passkey login
│       ├── devices/         # Device registration & remote session kill switch
│       ├── users/           # User profile, account export & GDPR deletion
│       ├── backups/         # Encrypted vault backup blobs & retention caps
│       ├── audit/           # Security audit event recording & user activity feed
│       └── dev/             # Mock token minting for local curl tests (non-prod)
├── queries/                 # SQL source files compiled by sqlc
├── migrations/              # SQL schema migration files (Goose)
└── pkg/                     # Packages exposed outside internal/
    ├── serverless/          # Public bridge for Vercel Go runtime builder
    ├── httpx/               # JSON encode/decode, size limits & error mapping
    ├── token/               # JWT HS256 access token minting & verification
    ├── idtoken/             # Google/Apple OIDC identity token verification
    └── applesecret/         # ES256 client secret minting for Apple Sign-In
```
